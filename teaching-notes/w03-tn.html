Week 03 Teacher Notes

Student Expectations At Home

  • Watch videos about HTML CSS block/inline and the box model. Take the quiz
  • Follow and implement the tutorial to continue the home page of the white water rafting site.

Class Lesson Suggestions

  • Guided Practice: Use Portal Page for Demonstrating different layout methods
    Demonstrate how to layout elements on the portal page using float, position, and flexbox
  • Guided Practice: Use Portal Page for Demonstrating the CSS Box Model
    Add elements to the portal page and give them margins, borders, padding, and width. Talk about how the box model works for html elements in CSS. Demonstrate the importance of the box-sizing property

Week 03 Goals

  • Learn about units of measures, block/inline, and pseudo selectors.
  • Demonstrate html layout using float, position, and flexbox.
  • Practice putting together a web page by following a tutorial.
