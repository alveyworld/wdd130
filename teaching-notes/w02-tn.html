Week 02 Teacher Notes

Student Expectations At Home

  • Watch videos about HTML CSS style and design. Take the quiz
  • Read the essential HTML and CSS tutorials at W3schools.com . Take the quiz.
  • Follow and implement the tutorial for the site plan and home page of the white water rafting site.

Class Lesson Suggestions

  • Guided Practice: Portal Page Demonstrate how to draw a wireframe for a portal page (class portfolio). Plan colors, fonts, and positions of elements on the page. Show student how to create the HTML structure from the wireframe using semantic tags and then do some basic styling and connect a css style sheet.
  • Guided Practice: Add to Portal Page Add lists, a table, a form, and continue to style the portal page with CSS selectors ID and Classes. Use external resources to choose color schemes and new fonts.

Week 02 Goals

  • Learn about basic wireframe and site planning.
  • Begin learning about all the major tags in HTML, focus on semantic tags.
  • Learn how to add CSS and use selectors with elements, ids, and classes
  • Practice putting together a web page by following a tutorial.
