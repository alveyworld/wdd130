Week 01 Teacher Notes

Student Expectations At Home

  • Install Visual Studio Code editor. Add Live Server Extention to VS Code.
  • Set up the local folders for the course files on their computers.
  • Watch preparation videos on web basics and take Web Basics Quiz online.
  • Research web terms to prepare for the Kahoot quiz in class (or online quiz).
  • Read Elder Ballard's talk about Sharing the Gospel using the Internet. Take the quiz.

Class Lesson Suggestions

  • Web Pioneer Group Research: (in class) Use the Jigsaw Learning technique. Split the class into 3 or 4 groups. Each group should pick one of the Web Pioneers to research. Use a fun interactive tool like Padlet. Have each group add pictures and facts about their Pioneer. Let the groups take turns teaching the rest of the class about their chosen Pioneer. (online) Use the discussion board to research and discuss student's favorite web pioneer.
  • Web Terms Quiz: (in class) Use an interactive quiz app like Kahoot to review the web terms (Kahoot Import File). (online) Take the Quick check quiz
  • Disciple Building: Discuss the responsibility we all have to share the gospel of Jesus Christ online. Use Elder Ballard's talk to guide the discussion.
  • Demonstrations:
    • File management: Review how to set up the folders for the course.
    • Editor basics: Demonstrate how to install the Live Server extention. Show common VSCode keyboard short cuts like copy, paste, multi cursors (alt), copy line (shift-alt-down).
    • Basic html page: Demonstrate writing the most basic html page with html, head, and body tags. (! VSCode trick)
    • Live Server: Show how to locally serve HTML pages to browser using the Live Server extention.
    • Portal page setup: Demonstrate creating the basic portal page with images and links and simple styles

Week 01 Goals

  • Basic technical setup success
  • Group Interaction to promote collaboration
  • Familiarity with basic web terms and people
  • Celestial perspective on purpose of creating information online
