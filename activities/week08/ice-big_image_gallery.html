In Class Exercise (ICE) Challenge: Big Image Gallery

Overview

  • Task: Create thumbnail images of an appropriate file size.
  • Purpose: Try using a photo editor to change image file size.
  • Expectation: ICE Challenges are designed to be completed in less than an hour. See what you can complete in an hour and then submit it.
  • Extra Credit Opportunity: You can receive bonus points for adding cool, creative, clever features to enhance the challenge

Instructions

  1. Open the files

    • Download the starter files

      Start by downloading the zip file: Gallery and unzipping it and saving the gallery folder in your ice folder

    • Open in VS Code

      Open the gallery folder in VS Code, then locate gallery.html and open to edit.

  2. Test it out

    • Open in a browser

      Test the gallery.html file by opening it in a browser like Chrome. Hold the shift key and click the browser's refresh button. What do you notice about how the images load?
      Turn on the "Inspect element" feature of your browser and choose the "Network" tab, shift-refresh again and see how many seconds it takes to load the images for the page. Do you notice a problem?

  3. Optimize the images

    • To optimize images you will need to use a photo editor like Photoshop (Adobe Express is available to all byui students) or an online editor like Photopea

    • Shrink the file size

      Optimize the images in the big folder using a photo editor. Maintain the resolution of the images (1950px by 2915px), but try to shrink the number of bytes it takes to store the images. This can be done by lowering the quality of the PNG image file or changing it to another web image type like JPG, GIF, or webP that optimize images. Then override or replace the images in the big folder with the optimized images and update the links.
      Example:
      given img1.png -> 10MB
      optimized img1.jpg -> 895KB
      Note: Optimizing images for the web uses lossy image compression where some pixel colors are lost to make the file smaller, but there is no noticable change to the image in the browser. This is good for helping web pages load images faster, but not so good if you want to print your images at high quality.

    • Create smaller thumbnail images

      Next optimize the page loading by creating separate thumbnail sized versions of the images. Open the big files in a photo editor and find a way to change the resolution of the images to the size defined in the css code (200px by 300px). This is usually done with an "Image Size" menu option of a photo editor. Then save the smaller thumbnail sized files to the small folder in images.

  4. Update the gallery

    • Use the thumbnails

      Change the src attribute of each image tag to point to the small thumbnail versions of the images. The href attribute of the link tag should point to the optimized big images.

  5. Submit

    Compress the gallery folder and submit the zip file.
    Note: If you optimized the files properly your new zip file should be less than 30MB
