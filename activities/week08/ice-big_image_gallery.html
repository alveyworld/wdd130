In Class Exercise (ICE) Challenge: Big Image Gallery

Overview

  • Task: Create thumbnail images of an appropriate file size.
  • Purpose: Try using a photo editor to change image file size.
  • Expectation: ICE Challenges are designed to be completed in less than an hour. See what you can complete in an hour and then submit it.
  • Extra Credit Opportunity: You can receive bonus points for adding cool, creative, clever features to enhance the challenge

Instructions

  1. Open the files

    • Download the starter files

      Start by downloading the zip file: Gallery and unzipping it and saving the gallery folder in your ice folder

    • Open in VS Code

      Open the gallery folder in VS Code, then locate gallery.html and open to edit.

  2. Test it out

    • Open in a browser

      Test the gallery.html file by opening it in a browser like Chrome. Hold the shift key and click the browser's refresh button. What do you notice about how the images load?

  3. Optimize the images

    • Create smaller thumbnail images

      Change the image size of the big images using a photo editor like Photoshop (Adobe Express is available to all byui students) or an online editor like Photopea. Then save the smaller thumbnail files to the images/small folder.

    • Shrink the file size

      Optimize the big images using the same photo editor. Maintain the deminsions of the files (1950px by 2915px), but try to shrink the number of bytes it takes to store the images. Using a different file type is acceptable (ie. png->jpg). Then override the images in the big folder with the optimized images and update the links.

  4. Update the gallery

    • Use the thumbnails

      Change the src attribute of each image to point to the small thumbnail versions of the images. Keep the link to the big images.

  5. Submit

    Compress the gallery folder and submit the zip file
