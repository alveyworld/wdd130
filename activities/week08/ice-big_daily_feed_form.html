ICE Challenge: Daily Feed Form

Overview

  • Task: Style a form used for collecting data.
  • Purpose: Practice CSS and look at javascript.
  • Expectation: ICE Challenges are designed to be completed in less than an hour. See what you can complete in an hour and then submit it.
  • Extra Credit Opportunity: You can receive bonus points for adding cool, creative, clever features to enhance the challenge

Instructions

  1. Open the files

    • Download the starter files

      Start by downloading the zip file: Signup and unzipping it and saving the signup folder in your ice folder

    • Open in VS Code

      Open the signup folder in VS Code, then locate signup.html and open to edit.

  2. Style the Form

    • Code the CSS

      Change the HTML and CSS to match the image below. Use grid where appropriate. Resize images if needed.

  3. Checkout the Javascript

    • Submit the Form

      Fillout the form and click submit. Study the javascript in signup.html (its in the script element) to see if you can make sense of the code. This is the kind of code you will be studying in WDD131.

  4. Submit

    Compress the signup folder and submit the zip file
