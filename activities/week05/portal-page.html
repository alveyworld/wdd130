WEB Fundamentals

WDD 130

Portal Page

Overview

  • Task: Design and Develop a web page that will be a portal to all your work in the class.
  • Purpose: Practice designing a web page with a wireframe and converting it to html/css.
  • Progress Checks: You will have 4 weeks to complete this task, each week you will submit your progress.
    • Progress Check 100 - Plan and Design
    • Progress Check 200 - Convert to HTML
    • Progress Check 300 - Convert to CSS
    • Progress Completed - About page and finishing touches

Background

You will need a place collect all the web pages you create for the class. So why not have that be your first web page you make. Web pages can make a great portfolio. We will call the your portal page. Make sure your portal page is well designed and developed. It Should include an "about me" page. The hope is that you make a nice design That you would be proud to use as a portfolio that you can use in the future.

Requirements

  • Plan: Wireframe, colors, logo, fonts
    Create a wireframe and design document that includes colors, logo, and font choices. The design document can be an html page, a word doc, google doc, or a picture of a handwritten document.
  • Sections: Header, Nav, Main, Footer
    Your design should include a header, navigation, main, and footer section.
  • Menu: Home, WWR, ICE, About Me
    Your navigation menu should have links to at least the 4 options home, wwr, ice, and about me. You can add more if you need.
  • Elements: Heading, Paragraph, Link, Image, List, Table, Form
    The content of your page should include at least one use of each of these html elements: h1-h6, p, a, ul, table, form. For list table and form make sure to also include appropriate helper elements.
  • Content: Text and Images
    Your portal should look like a completed web page. Write your own content or use Lorem Ipsum text to to fill in the sections. Create your own images or use AI to make images to fill in your design.
  • A.I.:
    Don't let AI write your code for you. Practice writing all the elements and styles yourself.
    (If you use ai to learn or remember, make sure you still type the code in manually.)

Instructions

  1. Plan and Design (Progress Check 100)

    • Wireframe

      Start by drawing a wireframe of your design. Draw it on paper and take a picture, or use a online design tool such as wireframe.cc or figma.com. Keep it simple and focus on the main elements and positions of the elements, don't worry too much about the little details.

    • Create a logo

      Design a logo, if you are not a professional designer feel free to use AI to help create the image. Save your logo as a web friendly image format such as jpg, png, webp, or gif

    • Color Scheme

      Decide on a small set of colors (5 or 6 colors) for your portal page. Use an online color app like Colors to help you choose colors that go well together. You can also use your logo to help you choose your colors.

    • Fonts choices

      Decide on a few font that you will use for your portal page. Choose from the basic web fonts, download a font file you can import, or import a font from another server like google fonts.

  2. Convert Design to Code

    • Structure with HTML (Progress Check 200)

      Add an index.html file in your wdd130 folder, then create the basic html elements. Add html elements for each of the parts of your wireframe. Use semantic html elements as much as possible. Add lorem ipsum content to fill the elements. Use the img element for images that you want as part of the content.

    • Style with CSS (Progress Check 300)

      Add a style.css file in your wdd130/styles folder, then add selectors for each of your html elements and begin to style your page. Use grid to style the layout of your HTML elements. Use the background properties for images that you will use for decorating elements.

  3. ICE page (Progress Completed)

    • New page using the same CSS

      Add an ice.html file in your wdd130 folder, copy the code from your index.html file. Keep the header, nav, and footer the same. This will ensure that the pages look similar and that you are using the same stylesheet for your ice challenge page. Then remove all the elements nested inside your main element.

    • Add ICE content

      Add elements in your main to present all your ice challenges. Describe each ICE challenge assignment and what you learned. Make sure there is a link to each ice challenge assignment. Links to the ice challenge pages should open in a new tab (add the attribute target="_blank" to your links).

  4. Submit

    Put your wireframe and design files into your wdd130 folder.

    Each week for your progress checks compress your wdd130 folder and submit the zip file
