In Class Exercise (ICE) Challenge: Holiday Page

Overview

  • Task: Style the given html for the holiday.
  • Purpose: Practice designing css without changing the html.
  • Expectation: ICE Challenges are designed to be completed in less than an hour. See what you can complete in an hour and then submit it.
  • Extra Credit Opportunity: You can receive bonus points for adding cool, creative, clever features to enhance the challenge

Instructions

  1. Open the files

    • Download the starter files

      Start by downloading the zip file: Halloween Page and unzipping it and saving the halloween folder in your ice folder

    • Open in VS Code

      Open the halloween folder in VS Code, then locate index.html and open to edit.

    • Download the starter files

      Start by downloading the zip file: Valentines Page and unzipping it and saving the valentines folder in your ice folder

    • Open in VS Code

      Open the valentines folder in VS Code, then locate index.html and open to edit.

    • Download the starter files

      Start by downloading the zip file: Father's Day Page and unzipping it and saving the fathersday folder in your ice folder

    • Open in VS Code

      Open the fathersday folder in VS Code, then locate index.html and open to edit.

  2. Style the page

    • Write the CSS, but don't change the HTML!

      Take the given HTML code and add your own css to color it and style the page to make it styled for the holiday. Have some fun, everyone's should look very different even though we are all using the same HTML code.

  3. Submit

    Compress your completed folder and submit the zip file
