Learning More: Frontend Development

Activity Directions

One of the goals of this course is to introduce you to different career options available in Web Design and Development. The first we will learn about is that of Frontend Developer.

Watch this introduction to this career by Treehouse (no need to sign up). It introduces the type of work you would be doing, along with the skills you would need to succeed. It will cover concepts and technologies you will learn in the future if you continue studying Web Development.

HTML and CSS are the foundational concepts you will need to be a frontend developer!
